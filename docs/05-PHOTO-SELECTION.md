# Photo Selection

## Goal
Do not generate 40+ clips for a normal listing.

Default target:
- 16–20 scenes

## Keep
- strongest exterior opener
- best entry / foyer
- best living-room angle
- strongest kitchen angle
- dining room if unique
- primary bedroom
- primary bathroom
- secondary bedroom only if meaningfully different
- secondary bathroom only if meaningful
- unique office / gym / theater / game room
- best backyard / pool / patio / dock
- strongest view
- strong closing hero image

## Remove
- duplicate bedroom angles
- duplicate bathroom angles
- near-identical kitchen photos
- weak hallway shots
- repetitive exterior angles
- detail photos with no storytelling value
- close-ups that add nothing to spatial understanding

## Rule
A photo belongs in the video only if it:
1. reveals a new space,
2. reveals an important feature,
3. improves the story,
4. or is clearly stronger than the alternatives.
