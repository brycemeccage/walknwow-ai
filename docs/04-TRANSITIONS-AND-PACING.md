# Transitions and Pacing

## Clip timing
Normal room:
- 3.0 to 3.3 seconds

Hero shot:
- 3.6 to 4.0 seconds

Bathroom:
- 2.8 to 3.0 seconds

## Transition
Use a true dissolve / crossfade.

Target:
- 0.6 to 0.8 seconds

Recommended default:
- 0.7 seconds

## What the viewer should feel
Clip A should gently disappear while Clip B gently appears.

Not:
Clip A -> instant cut -> Clip B

## Opening
Fade from black:
- ~1.0 to 1.5 seconds

## Ending
Fade into realtor outro:
- ~1.0 second

## Pacing
Do not rush through rooms.
Do not make every scene the exact same duration if a hero scene deserves slightly more time.
